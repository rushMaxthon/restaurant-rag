# Location Slot Demo Reference

This document lists the seeded demo operating windows used for mobile and QA testing.

All seeded restaurant locations now use:

- active delivery and pickup
- scheduled ordering enabled
- `30` minute slot intervals
- branch-specific weekly delivery windows
- branch-specific weekly pickup windows

Use this file to verify:

- branch switching changes available slot windows
- delivery vs pickup shows different times
- weekday tabs produce different slots
- ASAP availability respects branch closing windows
- scheduled slots change correctly by branch and day
