# Own Fleet — Plan 2 of 4: the Rider Android app

> Executed inline (superpowers:executing-plans). Spec:
> `docs/superpowers/specs/2026-10-08-rider-app-design.md`. API contract:
> `docs/superpowers/plans/rider-openapi.json` (exported from Plan 1).

**Goal:** a working, premium-feeling Android app for the platform's riders:
sign in, go online, get an order alert, accept, carry it step by step with the
customer's code, see earnings and history, manage the profile.

**Stack:** React Native 0.87.1 CLI (`rider/`), React 19.2, React Navigation 7
(native stack + bottom tabs), Reanimated 4.7 + Worklets 0.13, Gesture Handler 3,
react-native-svg, react-native-keychain (token), AsyncStorage (prefs),
@react-native-community/geolocation, NetInfo, haptics, Ionicons. Jest for logic.

## Constraints

- Android first; `com.foodie.rider`; API base `http://localhost:8000/api` in debug
  with `adb reverse tcp:8000 tcp:8000` (works for the emulator AND a USB phone).
- Every disabled control says why (house rule). Touch targets >= 48 dp.
- Token in the Android Keystore (Keychain), never AsyncStorage.
- Trip actions carry a client `action_id`, reused on retry; queued while offline.
- A 401 on the current token signs out with a sentence on the login screen.
- Not yet (blocked on the user's accounts): in-app Google map (Maps billing),
  FCM push while the app is closed (`google-services.json`). Until then: offer
  polling every 3 s while online and in the foreground; Navigate opens Google Maps.

## Navigation

```
Root stack
  Splash (animated) -> decides
  Login                        (signed out)
  Permissions                  (signed in, location/notifications missing)
  Main tabs                    (signed in)
     Home      - map-first header, online toggle, today, active trip card
     Earnings  - today / 7 days, bar per day, unpaid vs paid
     History   - finished trips, infinite list
     Profile   - rider, vehicle, theme, support, sign out
  Offer        (full-screen modal over tabs: countdown, accept / decline)
  Trip         (pushed: stepper, stops, call, navigate, slide actions, OTP)
  Delivered    (celebration, earning, back to Home)
```

Bottom tabs (not a drawer): one-handed use on a bike; every destination one
thumb-tap away; the active trip stays reachable from Home.

## Tasks

1. **Core**: `config/api.ts`, `services/http.ts` (timeout, JSON, error -> sentence,
   401 hook), `services/session.ts` (Keychain), `store/SessionProvider.tsx`,
   `services/rider.ts` (typed endpoints from the contract), `utils/format.ts`
   (₹, km, minutes). Tests: http error mapping, format.
2. **Shell**: Splash (logo + wordmark spring-in), Login (phone + password, show
   password, inline errors, keyboard-safe), animated custom tab bar, theme in
   React Navigation.
3. **Home + shift**: `hooks/useRider.ts` (me + status), `hooks/useLocationReporter.ts`
   (watch position while online; batch every 10 s on a trip / 60 s idle),
   `hooks/useOfferWatcher.ts` (poll current offer, open Offer modal once per id).
4. **Offer**: full-screen card, CountdownRing, earnings, distances, accept/decline,
   haptic + vibration pattern, auto-close on expiry/withdrawn.
5. **Trip**: stepper, pickup/drop cards, call (tel:), navigate (google.navigation:
   intent, falls back to maps URL), SlideToConfirm per step, OTP 4-box sheet with
   attempts left, customer-unavailable flow (calls logged, timer), offline queue.
6. **Delivered**: animated check (SVG stroke draw) + earning count-up.
7. **Earnings / History / Profile**.
8. **Permissions** screen gating "Go online".
9. Verify: tsc, jest, release-like debug run on the emulator against the local
   API with a real rider account, every screen at 393 dp and in dark + light.
